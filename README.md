# PlaceIQ

Explainable semantic shortlisting for campus placement. A local language model reads a free-text company requirement and extracts the required skills and the eligibility rules (CGPA, branch, backlogs). The rules filter the student pool, a vector index retrieves the nearest resumes, and the same model scores each retrieved resume and explains the score. Everything runs on one laptop (6 GB GPU); student data stays on the machine. The system is evaluated on a **synthetic** benchmark only (500 students, 15 requirements).

## Features

- **Top-10 shortlist** with matched and missing skills and a two-sentence explanation per candidate (the frozen configuration evaluated in the paper: tag `frozen-main-config`).
- **Keyword ATS vs Ours:** compares a strict keyword filter with the shortlist and shows which keywords the filter missed.
- **All suited candidates** (prototype extension): re-scores the 50 best hybrid-retrieval candidates and lists everyone at or above a threshold, with CSV export.
- **Student view** (prototype extension): a student's fit for a requirement, eligibility check, skill gaps, suggestions and a what-if projection.
- **Evidence** and **Fairness and limits** tabs with the final numbers.

The two prototype extensions are not evaluated; see `docs/EXTENSIONS.md`.

## Setup

1. Python 3.12 virtual environment in `.venv` and `pip install -r requirements.txt`.
2. [Ollama](https://ollama.com) with the model stored on the D: drive:
   ```
   set OLLAMA_MODELS=D:\ai-cache\ollama
   ollama serve
   ollama pull qwen3.5:4b-q4_K_M
   ```
3. The embedding model (`BAAI/bge-small-en-v1.5`) downloads on first use into `D:\ai-cache\hf` (see `scripts\run_demo.bat`). The vector index (`data/chroma`) is rebuilt automatically when missing.

## Run the demo

```
cd D:\placement-matcher
scripts\run_demo.bat
```

The app opens at http://localhost:8501. Wait for "Local LLM: ready" in the sidebar before running a custom requirement; the 15 sample requirements also work from the call cache. A 5-minute demo script is in `docs/DEMO.md`.

| `docs/` | data description, results, demo guide, extension notes, prompt log |

## Limitations

Synthetic data only: students, resumes and requirements are generated, and the labels come from the same generator. Results on the 10 test requirements have wide intervals and say nothing about real placement outcomes. The tool is decision support; a person reviews every shortlist. The fairness test covers names only.
